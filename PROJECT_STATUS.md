# État du projet

## Niveau actuel

Prototype avancé / préproduction locale.

## Utilisable pour

- expérimenter l'ingestion de PDF ;
- analyser des documents en local ;
- tester le routage multimodal ;
- produire des artefacts page par page ;
- développer le futur RAG.

## Pas encore validé pour

- exposition publique sans authentification ;
- facturation cloud sans contrôle manuel ;
- reprise garantie après arrêt brutal ;
- recherche vectorielle de production ;
- traitement autonome sans audit d'un corpus réel.

Voir `docs/AUDIT_V0.5.md`.
