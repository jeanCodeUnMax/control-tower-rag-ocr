# 12. Limites et feuille de route

## Limites V0.5

- reprise après redémarrage incomplète ;
- recherche encore majoritairement lexicale ;
- consolidation inter-documents limitée ;
- coût cloud estimé, pas totalement réconcilié avec la facture ;
- API à réserver au localhost ;
- providers cloud non validés avec les clés de l'utilisateur ;
- modules de raisonnement encore heuristiques.
