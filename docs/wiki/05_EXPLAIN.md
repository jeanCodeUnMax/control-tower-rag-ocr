# 5. Comment expliquer le projet

## Version simple

Control Tower RAG transforme des documents longs en une base de connaissances contrôlée. Chaque page est suivie, les images et le texte sont analysés selon leur difficulté, puis les répétitions sont regroupées avant la recherche.

## Version professionnelle

La plateforme orchestre l'ingestion documentaire multimodale par projet isolé. Elle combine extraction native, OCR, analyse visuelle optionnelle, traitement par lots adaptatifs, contrats JSON, consolidation canonique et recherche avec traçabilité complète des sources.

## Différence avec un RAG classique

Un RAG classique peut découper et indexer presque aveuglément. Control Tower ajoute :

- registre de complétude ;
- choix adaptatif du moteur ;
- artefacts page par page ;
- politiques ;
- consolidation des doublons ;
- isolation stricte par projet ;
- enrichissement différé.
