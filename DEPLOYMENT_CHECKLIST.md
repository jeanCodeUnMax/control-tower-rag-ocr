# Checklist de déploiement

- [ ] Python 3.11 disponible
- [ ] Tesseract installé avec langues requises
- [ ] `.env` créé sans être committé
- [ ] `CONTROL_TOWER_HOME` placé sur un volume persistant
- [ ] tests `pytest -q` réussis
- [ ] projet de test créé
- [ ] préflight exécuté sur un PDF réel
- [ ] benchmark de 10–20 pages effectué
- [ ] budget cloud configuré
- [ ] sauvegarde du workspace configurée
- [ ] API limitée à localhost ou protégée par reverse proxy
- [ ] audit V0.5 lu
